### Warning

This extension still requires more extensive testing. Backup your data before using it.

### Description

Stops the game from deleting lot objects on move out. Also adjusts the lot value to account for the objects.

### Compatibility

Works only with the Ultimate Collection. Doesn't work with the Legacy Collection.

### Requirements

Requires either TS2Extender or Ultimate ASI Loader.

### AI Statement

The address of the lot object deletion code and the data to overwrite it with were found using AI.
